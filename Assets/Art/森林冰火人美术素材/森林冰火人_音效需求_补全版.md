# 森林冰火人音效需求

用于音效制作、素材筛选与游戏接入。保留原《音效需求.md》的项目，并结合《森林冰火人_完整玩法策划案.md》和《游戏流程.docx》补充触发条件、声音表现、循环方式与流程反馈。

**本文件是音效需求，不是音频素材交付，也不修改玩法规则。** 所列音色、时长、变体数量、混音与播放限制均为本次补充建议；来源中不一致或未明确的玩法单独列为待确认。

## 1 范围与制作说明

### 1.1 来源标记

| 标记 | 含义 |
| --- | --- |
| 原清单 | 原《音效需求.md》已列出，本文补充制作与播放要求 |

| 待确认 | 原资料存在冲突，或对象、规则尚未说明；不直接作为确定制作项 |

### 1.2 优先级与声音方向

- **P0**：核心操作、解谜结果、受伤死亡、基础 UI、切面与通关，优先覆盖可玩流程。
- **P1**：环境层次、细化变体、次要提示、剧情语音，在对应内容接入时补足。
- **待确认**：保留需求位置，确认玩法后安排制作。

建议整体采用轻巧、清晰、带少量奇幻感的声音。木头、金属、液体、火焰具有可辨材质；数字变化和镜片使用短促的清亮音色。高频操作保持短小，避免持续尖锐声或过长尾音。

表中“一次”为事件发生时播放一次，“循环”为状态持续期间播放，“按动作”为脚步或划水等随动作重复的短音。表中 ID 是事件编号，**不等于每行必须单独制作一个文件**；明确写明复用的事件可共享素材。

## 2 人物运动音效

| ID | 音效 | 触发与停止条件 | 声音表现与播放方式 | 优先级与来源 |
| --- | --- | --- | --- | --- |
| MOV-01 | 地面跳跃 | 合法起跳成功时；空中无效按键不响 | 轻蹬地加短风切，一次；建议 0.15～0.35 秒，2～3 个轻微变体 | P0 · 原清单 |
| MOV-02 | 奔跑脚步 | 接地且实际移动，随脚落地触发；停步、离地、游泳时停止 | 短脚步，按动作；按已使用地表区分石地、木面、金属面，建议每类 3～4 个变体 | P0 · 原清单 |
| MOV-03 | 普通落地 | 从空中落到有效支撑面时 | 轻短撞击，一次；与当前地表材质匹配，避免接地抖动重复播放 | P0 · 玩法补齐 |
| MOV-04 | 高处跌落与重落地 | 较大下落速度后实际落地；落入液体改用液体反馈 | 比普通落地更厚重的一次冲击，替代普通落地；可加很轻的下落风声。阈值由实机调节 | P0 · 原清单 |
| MOV-05 | 受伤 | 毒液、普通火焰等造成实际非致命扣血时 | 短促受击声，可加克制的角色反应；一次，建议 0.2～0.5 秒；免疫期间不重复响 | P0 · 原清单 |
| MOV-06 | 入水或入毒液 | 身体有效进入液体，发生真实入液事件时 | 水花一次；毒液可叠少量黏稠气泡，不替代受伤声 | P0 · 玩法补齐 |
| MOV-07 | 游泳与静浮 | 游动时随划水动作触发；静浮仅保留稀疏轻水声；离液停止 | 轻划水，按动作，建议 3 个变体；静浮音量低于游动 | P0 · 原清单 |
| MOV-08 | 出水跳与出水 | 成功离开液体时；水下无效跳跃不响 | 短水花、滴水与轻蹬水声，一次；出水跳可复用跳跃底层，但不重复堆叠整段地面起跳声 | P0 · 玩法补齐 |
| MOV-09 | 进入上升气流 | 角色实际进入草垛气流并受到托举时 | 短上扬风切，一次；持续风声由场景气流提供，角色不再叠加一条长循环 | P1 · 玩法补齐 |
| MOV-10 | 爬梯子 | 仅在确认加入梯子及攀爬动作后，按手脚接触触发 | 木梯轻吱呀或金属梯短碰撞，按动作；停在梯上时静音 | 待确认 · 原清单；归入人物运动 |

说明：高处跌落目前只要求声音反馈。策划案未明确普通落地造成摔伤，不因重落地声新增扣血规则。坠出关卡边界的死亡使用流程中的死亡事件。

## 3 人物交互音效

| ID | 音效 | 触发与停止条件 | 声音表现与播放方式 | 优先级与来源 |
| --- | --- | --- | --- | --- |
| ACT-01 | 抓住与松开数字 | 抓取状态真正建立或解除时 | 轻接触短音，一次；松手可复用更轻版本，避免按住 Q 连续触发 | P1 · 玩法补齐 |
| ACT-02 | 推拉数字 | 数字与地面接触且实际滑动时起声；停止、离地、销毁或解除有效推拉后停止 | 木块摩擦、金属刮擦、红蓝块的轻硬质摩擦；短片段循环，速度影响节奏与音量 | P0 · 原清单 |
| ACT-03 | 推拉受阻 | 正在推拉且确实遇到阻挡时 | 轻闷碰一次，可复用碰撞声；持续顶墙不反复敲击 | P1 · 建议 |
| ACT-04 | 拾取数字 | 世界中的数字成功转入背包的提交时刻 | 轻收取声，一次；可用很轻的材质尾音区别类型 | P0 · 原清单 |
| ACT-05 | 放置道具 | 数字成功从背包转移到场景时 | 短放手声，一次；后续真正碰地再由碰撞系统发声，放入空中或液体不提前播落地声 | P0 · 原清单 |
| ACT-06 | 向机关内插入数字 | 数字成功进入插槽时 | 清晰卡入、扣合声，一次；应与普通放置明显不同 | P0 · 原清单 |
| ACT-07 | 从机关回收数字 | 数字成功由插槽转入背包时 | 轻解扣加抽出声，一次；与插入形成相反的声音方向 | P0 · 玩法补齐 |
| ACT-08 | 交换槽内数字 | 若启用直接交换，在交换成功提交时 | 一段紧凑的解扣再扣合声；可由回收与插入素材组合，不能误播两次完整拾取 | 待确认 · 玩法补齐 |
| ACT-09 | 操作失败 | 满包、空背包格、距离失效、放置受阻等明确拒绝操作时 | 统一轻短否定声，一次；配合文字说明具体原因，同一原因长按不连响 | P0 · 玩法补齐 |

拾取、放置、插拔声音跟随**成功提交**，不单纯跟随按键或动画开头。提交前受伤打断，不播放成功声；提交后再被打断，不回播或重播。

## 4 数字与环境交互音效

### 4.1 数字物体与液体

| ID | 音效 | 触发与停止条件 | 声音表现与播放方式 | 优先级与来源 |
| --- | --- | --- | --- | --- |
| ENV-01 | 数字碰撞与落地 | 数字真正撞击地面、墙、平台或另一块数字，冲击达到可听阈值时 | 木质闷敲、金属轻铛、红蓝硬质轻响；一次，建议每种材质 2～3 个变体 | P0 · 玩法补齐 |
| ENV-02 | 数字落入水或毒液 | 世界中的数字穿过液面时 | 水花或黏稠水花，一次；大小随实际冲击调整，不为每个数字值单独录音 | P0 · 玩法补齐 |
| ENV-03 | 数字接触岩浆 | 数字真实接触岩浆时 | 低沉黏稠气泡或热液翻动，一次；若当次发生熔毁，合并到熔毁声中 | P0 · 玩法补齐 |
| ENV-04 | 数值增加 | 游戏结算后新值大于旧值，例如红数受火或蓝数入水 | 清亮上行短音，一次；显示实际变化值，声音不承担报出数字的任务 | P0 · 玩法补齐 |
| ENV-05 | 数值减少 | 游戏结算后新值小于旧值 | 与增加声同音色的下行短音，一次；减值不等于操作失败，不使用失败警报 | P0 · 玩法补齐 |
| ENV-06 | 数值达到边界且未变化 | 环境反应合法结算，但被 0 或 100 的边界限制，前后数值相同 | 可用极轻中性短音或保持静音；不播增加、减少或销毁声 | P1 · 建议 |
| ENV-07 | 普通数字改变材质 | 普通数字在合法变值后发生木制与金属切换 | 木转金属为清脆凝结，金属转木为柔和松解；一次，可与变换门成功声合成一段 | P0 · 玩法补齐 |
| ENV-08 | 数字损失提示 | 某件数字被规则实际销毁，损失提示出现时 | 简短低落提示，一次；优先与销毁声合并，不作为角色死亡或整关失败音 | P0 · 玩法补齐 |

数字漂浮、沉底不另设长提示音；通过入液声、必要的后续碰撞声和视觉反馈表达。红蓝数字的浮沉与重复入液规则见待确认事项，音效统一读取实际结算事件。

### 4.2 火焰 草垛与危险环境

| ID | 音效 | 触发与停止条件 | 声音表现与播放方式 | 优先级与来源 |
| --- | --- | --- | --- | --- |
| ENV-09 | 箱子或木制数字着火 | 可燃木制对象由未燃烧变为燃烧时 | 短促引燃声，一次；原“箱子”先按木制数字对象整理，独立箱子待确认 | P0 · 原清单 |
| ENV-10 | 木制数字持续燃烧 | 数字处于燃烧状态时开始；熄灭、销毁或转换为金属时停止 | 细小木材噼啪声，循环；小于固定火源和草垛的声势 | P0 · 玩法补齐 |
| ENV-11 | 木块熄火 | 燃烧木块因水、毒液、入包或变为金属而实际熄灭时 | 入液用短嘶声；入包或变材质用干燥收束声；一次，避免所有熄火都像落水 | P0 · 玩法补齐 |
| ENV-12 | 木块燃尽 | 木制数字达到累计燃烧寿命而销毁时 | 干裂、塌散、灰烬消失，一次；同时停止燃烧循环 | P0 · 玩法补齐 |
| ENV-13 | 木块或蓝色数字被岩浆熔毁 | 对象接触岩浆并被立即销毁时 | 短熔蚀声；木块可带焦裂，蓝块可带硬质碎解；一次，不等待燃烧过程 | P0 · 玩法补齐 |
| ENV-14 | 草垛着火 | 未点燃草垛被有效火种首次点燃时 | 比木块更饱满的“呼”声，一次；草垛已燃烧时再次接触不重复点火 | P0 · 原清单 |
| ENV-15 | 草垛燃烧与上升气流 | 草垛点燃后持续；重开或卸载场景时停止 | 火焰与向上风声分层循环；强度跟随实际草量输出，不跟随火种数字大小 | P0 · 玩法补齐 |
| ENV-16 | 固定火源环境声 | 火源存在且处于可听范围时 | 稳定火焰循环，与小木块燃烧区别；远离衰减 | P1 · 玩法补齐 |
| ENV-17 | 水 毒液 岩浆环境声 | 对应液体在可听范围时 | 水为稀疏波纹；毒液为黏稠气泡；岩浆为低频翻涌与气泡。分别循环，不能用同一条水声代表三者 | P1 · 玩法补齐 |

暂不增加草垛燃尽、风助燃、水火混合爆炸、持续中毒尾声等音效；这些事件在当前玩法中没有确定依据。

| MEC-12 | 变换门运算成功 | 数字完整穿过且合法运算提交时 | 短穿越声与增减方向提示组合，一次；材质改变时加入相应层，避免三条完整成功音叠播 | P0 · 玩法补齐 |
| MEC-13 | 变换门拒绝 | 非整数、越界或其他规则导致本次穿越被拒绝时 | 轻弹回加否定音，一次；保持在门口不逐帧播放，配合失败原因 | P0 · 玩法补齐 |
| MEC-14 | 按钮按下 | 按钮由未有效按压转为有效按压时 | 清楚短“咔嗒”，一次；地面、侧面、顶部按钮可共用，持续压住不重复响 | P0 · 玩法补齐 |
| MEC-15 | 按钮松开 | 有效按压状态解除时 | 比按下更轻的复位声，一次；多物体交叠时以最终按钮状态为准 | P0 · 玩法补齐 |
| MEC-16 | 封锁打开 | 全部条件满足，封锁实际解除时 | 栅栏用解锁滑动；镜面屏障用共鸣消散，按最终美术二选一；一次或短运行段 | P0 · 玩法补齐 |
| MEC-17 | 封锁关闭 | 条件失效且封锁真正开始关闭时 | 与打开配套的关合声；门内有物体而暂缓关闭时不提前播放关门落锁声 | P0 · 玩法补齐 |

按钮按下、封锁打开与关卡完成属于三个不同事件。按下一个按钮、打开通路时，不播放取得拼图或最终胜利音。

## 6 UI 音效

主菜单、设置、选关、暂停和结算尽量共用一组基础 UI 声音，靠少量功能提示区分事件，减少素材数量和听觉负担。

| ID | 音效 | 触发条件 | 声音表现与复用要求 | 优先级与来源 |
| --- | --- | --- | --- | --- |
| UI-01 | 悬停与焦点移动 | 鼠标进入新可用按钮，或键盘焦点移到新项目时 | 极轻短音；同一控件内部移动不反复响 | P1 · 流程补齐 |
| UI-02 | 点击与确认 | 有效点击开始、继续、游玩、下一关、确认等按钮时 | 清脆短确认声，一次；不同页面共用 | P0 · 流程补齐 |

## 7 过关与游戏流程音效

| ID | 音效 | 触发条件 | 声音表现与播放关系 | 优先级与来源 |
| --- | --- | --- | --- | --- |
| FLOW-01 | 进入关卡 | 加载完成并开始本关可操作流程时 | 简短进入提示，一次，建议 0.3～0.8 秒；重试可简化，避免反复拖长等待感 | P1 · 流程补齐 |
| FLOW-02 | 存档点激活与保存成功 | 若采用存档点，在实际激活且保存成功时 | 温和确认短音，一次；持续站在同一存档点不连响，未保存成功不播放成功声 | 待确认 · 流程补齐 |
| FLOW-03 | 拼图或主收集物拾取 | 角色成功获得镜之碎片等确定收集物时 | 清亮镜片共鸣与收取声，一次，建议 0.4～0.8 秒；与普通数字拾取区分 | P0 · 原清单及玩法补齐 |
| FLOW-04 | 每面完成 | 本面完成条件已经成立时 | 短成功音，一次，建议 0.6～1.2 秒；若与拼图收取是同一时刻，制作成一段组合声 | P0 · 原清单细化 |
| FLOW-05 | 每面切换 | 场景开始切换或转场画面开始时 | 短镜面掠过或空气转场声，一次，建议 0.3～0.8 秒；不与最终胜利混用 | P0 · 原清单 |
| FLOW-06 | 过面后背包数字清除 | 采用流程稿规则且实际有未使用数字被清除、提示出现时 | 一段轻散去声，一次；一次清多件不逐件密集响，空背包不播清除提示 | P0 · 流程补齐 |
| FLOW-07 | 角色死亡 | 生命归零、岩浆接触或掉出边界等死亡事件实际成立时 | 短死亡声，一次；普通死亡、岩浆死亡可有不同起音，避免同时播放完整受伤加完整死亡 | P0 · 玩法补齐 |
| FLOW-08 | 失败提示 | 失败状态或失败界面实际出现时 | 简短低落音，一次，建议 0.4～0.8 秒；自动快速重开时可与死亡声合并，不额外延长复位 | P0 · 原清单 |
| FLOW-09 | 重开与复位完成 | 重开或读取存档成功，进入恢复后的场景时 | 轻重置提示，一次，建议 0.2～0.5 秒；目标为整关或存档点均复用，按最终规则接入 | P0 · 玩法及流程补齐 |
| FLOW-10 | 最终胜利 | 全部规定目标完成，正式进入终局胜利时 | 较完整、明亮的胜利收束，一次，建议 2～4 秒；仅最终胜利使用，给结局对白留空间 | P0 · 原清单 |
| FLOW-11 | 结算界面出现 | 游戏结束弹窗显示时 | 若已经播放最终胜利音，面板不再叠一个成功音；需要单独出现时复用普通弹窗声 | P0 · 流程补齐 |
| FLOW-12 | 结算数值与评级揭示 | 总时长、总得分、评级实际逐项出现时 | 时长与分数用少量短刻度，评级用一声揭示；若静态一次展示则无需逐项音 | P1 · 流程补齐及建议 |

**流程组合建议：**

- 普通过面：成功收集 → 短完成反馈 → 转场；若启用过面清包，则在清包发生时插入轻消散声。
- 死亡重试：死亡或合并失败声 → 清理旧场景声音 → 复位成功提示 → 恢复环境声。
- 最终胜利：最终目标完成 → 胜利音 → 结局对白或结算；不再连续叠加普通完成曲和另一段结算成功曲。

以上顺序跟随实际流程事件，不以音频长度反过来决定通关、保存或重置时机。“每面”暂指流程稿中的单个游玩场景，和“关卡”的确切关系见待确认事项。

## 8 旁白与剧情声音

旁白语音与音效分开管理。策划案允许先做字幕和触发逻辑，再接语音；本节为录音需求预留，不要求首轮先完成全部对白。

| ID | 内容 | 触发与表现 | 优先级与来源 |
| --- | --- | --- | --- |
| VO-01 | 首次遭遇与机关引导 | 在首次观察关键机关或安全入口时触发；语气略带挑衅，句子短，不遮盖操作反馈 | P1 · 玩法补齐 |
| VO-02 | 分层提示 | 卡关计时或主动请求被接受后播放当前有效提示；过时提示撤销，不在解开后继续讲旧答案 | P1 · 玩法补齐 |
| VO-03 | 重试与失败回应 | 根据实际重试记录触发，避免每次死亡重复同句长台词 | P1 · 玩法补齐 |
| VO-04 | 成功与意外解法回应 | 玩家确实完成对应布置或解法后触发；不猜测未成立的物理结果 | P1 · 玩法补齐 |
| VO-05 | 公主短讯与终局对白 | 在镜片剧情或营救阶段的明确节点触发；与最终胜利音错开主要对白段 | P1 · 玩法补齐 |

播放约束：

- 同时只播一句主要对白；按策划案同类台词至少间隔 12 秒，最终时机以对白系统为准。
- 暂停时冻结语音进度，恢复后从原位置继续；重开时清理旧关卡待播队列，保留的已听记录由剧情系统决定。
- 普通对白不自动暂停危险；危险时优先保留受伤、死亡和关键操作声。
- 字幕开关与语音开关分开；关闭语音后仍可保留字幕。
- 每句台词提供独立文件及台词 ID、说话人、文本、触发条件、可否打断、重复限制。具体台词数量另按最终剧情表统计。

背景音乐不计入本次音效清单。若同时安排配乐，可另列主菜单、解谜、终局三个使用场景；曲数、长度和音乐风格需另行确定。

## 9 播放规则与交付要求

以下是建议接入规范，均需结合实际游戏调试。

### 9.1 防止误报与重复播放

1. **按事件结果播放。** 操作成功、数值变化、实际扣血、机关启停、保存成功都以系统确认结果为准。
2. **按状态变化启停。** 机关循环只在进入运行状态时创建一次；每帧更新强度，不每帧新建声音。
3. **无效动作不播成功声。** 空中乱按跳跃、满包拾取、阻挡放置等按实际拒绝原因处理。
4. **近距离碰撞去重。** 同一对物体的轻微抖动不持续敲击；建议碰撞和失败提示设置约 0.15～0.3 秒的最短间隔，具体数值实测调整。
5. **复合事件控制层数。** 变换门运算、材质变化与数值变化可合成为一段；熔毁与数字损失提示也可合并。玩家应听清一次结果。
6. **遵守游戏事件优先级。** 同帧已经判死亡，不播放通关成功；进入完成状态后不再播放新伤害反馈。
7. **暂停与卸载正确清理。** 暂停冻结世界循环和语音，但 UI 仍可发声；重开、切面和返回菜单时停止旧场景声音，避免残留火声、风声或待播对白。

### 9.2 空间与混音

- UI、通关和非场景旁白使用稳定的非空间化声音；机关、液体、火源、碰撞按画面位置左右定位并随距离衰减。
- 重要反馈应能压过环境底噪。死亡、实际受伤、交互拒绝、数值变化、封锁开启优先于装饰环境声。
- 旁白播放时可轻降音乐和环境声，不把关键受伤声一并压没。
- 多个同类机关同时工作时限制总响度与实例数；远处环境可以合并，近处当前交互对象优先保留。
- 数字增减、确认取消等除音高外也使用不同节奏或音色，并配文字与视觉反馈，不只靠听觉传递规则。
- 音乐与音效控制至少匹配流程稿界面；旁白音量或语音开关按玩法案设置功能接入。总静音时 UI 试听也遵守静音。

### 9.3 文件交付

| 项目 | 建议要求 |
| --- | --- |
| 母版 | WAV PCM，48 kHz，24 bit；接入压缩格式由项目配置决定 |
| 声道 | 定位用角色、物体、机关素材优先单声道；UI 可单声道；宽环境氛围按需要立体声 |
| 短音时长 | 多数操作与 UI 约 0.1～0.5 秒；超过此范围有明确动作理由即可，不为凑时长剪掉必要尾音 |
| 循环长度 | 机关约 2～6 秒，环境约 8～20 秒；仅作制作起点，以循环不突兀为准 |
| 循环接缝 | 无爆音、无明显停顿；启动、循环、停止可分文件，并记录衔接关系 |
| 电平与尾音 | 无削波与意外底噪，同类响度接近；保留合理余量；短音不带多余前后静音 |
| 变体 | 高频脚步、碰撞、划水提供少量变体并避免连续重复同一条；UI 无需大量变体 |
| 命名 | 使用事件含义、材质、阶段、变体编号，例如 `sfx_mov_step_stone_01.wav`、`sfx_mec_fan_loop_01.wav` |
| 配套清单 | 标明对应需求 ID、文件名、时长、是否循环、声道、复用关系、版本与备注 |
| 外部素材 | 保留来源链接、作者、授权范围及必要署名文件；是否满足发布用途须按实际授权核对 |

建议文件夹按 `人物运动 / 人物交互 / 数字环境 / 机关 / UI / 流程 / 语音` 分组。每种数字不按 0～100 单独制作 101 套声音；按材质、事件与实际输出参数复用。

## 10 待确认事项

| 事项 | 资料中的情况 | 本需求的处理 |

## 11 接入验收清单

- [ ] 原清单中的跳跃、奔跑、高处跌落、受伤、游泳、推拉、拾取、放置、插入、箱子着火、草垛着火、风扇、流水、收集、爬梯、切面、最终胜利、失败均有对应条目；待确认项明确可见。
- [ ] 地面跳、出水跳、普通落地、重落地及入液声能区分；无效跳跃不发成功声。
- [ ] 拾取或插拔提交前被打断没有成功声；提交后仅播放一次。
- [ ] 木、金属与红蓝硬质数字具有可辨材质；轻微物理抖动不产生密集碰撞声。
- [ ] 数值增加、减少、材质变化、非法运算与数值边界不误报；同一次复合变化没有过量叠音。
- [ ] 木块点燃、熄灭、燃尽与岩浆熔毁能区分；草垛持续火风声能正确启停。

- [ ] 按钮按下与松开、封锁打开与关闭反馈正确；开门不等同于通关，延迟关门不提前落锁。
- [ ] 毒液与普通火伤只随有效扣血发声；死亡与同帧成功判定不同时发声。
- [ ] 主菜单、继续游戏不可用、选关、设置试听、退出确认、不可逆提醒、教程、暂停与恢复均有合适反馈。
- [ ] 每面完成、转场、背包清除与最终胜利按实际事件播放，空背包和重复进入结算不误触发。
- [ ] 存档点若启用，只在保存成功后播放成功声；恢复过程不遗留旧场景声音。
- [ ] 暂停冻结世界声与旁白，恢复不重复起音；重开清理过时对白。
